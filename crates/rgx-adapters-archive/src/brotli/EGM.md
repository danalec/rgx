# brotli

## Overview

An in-house RFC 7932 (Brotli) decoder, written for rgx rather than taken from
a library. It implements the whole format: the stream header and window size,
meta-block headers, block switching with relative block-type symbols, the
context maps, the insert-and-copy command alphabet, backward references with
the four short distance codes, the static dictionary, and that dictionary's
121 word transformations. The implementation is verified against files
emitted by the reference `brotli` CLI; the vectors live in the crate's
`testdata/brotli_README.md`.

`mod.rs` is the decoder itself: the stream walk, the command alphabet and the
forward references. `prefix.rs` holds the bit packing (§1.5.1 — least
significant bit first, unlike the prefix codes, which are reversed when the
decode table is built) and the prefix-code reader of §3. `context.rs` computes
the literal context ID of §7.1 from the last two uncompressed bytes. `tables.rs`
carries the RFC's normative tables — the 122 784-byte static dictionary, the
transform sequence, and the three literal-context lookup tables — generated by
`scripts/gen-brotli-tables.py` from the RFC text itself and checked against
the CRC-32 values the RFC prints for each blob. `error.rs` names the failure
modes, one per field of the format.

## Interface
- `pub struct BrotliDecoder` — `pub const fn new() -> Self` and `pub fn decode_bounded(&self, data: &[u8], limit: u64) -> Result<Bounded>`. The decoder is cheap to name rather than to carry around: every method takes `&self` and builds its own state, because the whole stream is in memory either way and there is nothing to keep between calls.
- `pub use error::{Error, Result}` — `Error` is `Truncated`, `Padding`, `Code`, `CodeLength`, `Symbol`, `Reserved`, `Range`, `Overflow` or `Budget`; `Result<T> = core::result::Result<T, Error>`.
- `pub fn literal_context(mode: u8, p1: u8, p2: u8) -> u8` (in the private `context` module; re-exported to the crate's tests as `context_for_test`) — the context ID for the next literal, always `0..63`.
- `prefix::Bits<'a>` (in the private `prefix` module) — the bit cursor over the whole input: `new`, `peek(n)`, `take(n)`, `bit()`, `align()`, `skip_bytes(n)`, `take_bytes(n)`, and the prefix-code reader `PrefixCode`.
- `tables::Kind` (in the private `tables` module) — the 21 elementary transforms in the order the RFC numbers them (`Identity` through `OmitLast9`); `tables::Transform { prefix, kind, suffix }` — one of the 121 transforms; `tables::DICT` — Appendix A's static dictionary; `LUT0`, `LUT1`, `LUT2` — the three literal-context lookup tables.
- `#[cfg(test)] pub mod coverage` — the counters the corpus-coverage test measures: dictionary words, transforms by kind, simple and complex prefix codes, block switches, short and direct and computed distances, context modes and maps, and the window sizes seen.

## Invariants
- The byte cap is enforced *as bytes are emitted*, not measured afterwards, so a bomb costs the budget and no more. The budget is `Error::Budget`, which is the only variant that is not a defect in the stream at all.
- Brotli declares no content size anywhere in the container, so `Bounded::declared` is always `None` and there is nothing to say about how much was left out.
- Peeking past the end of the input reads zeroes, which is what the last symbol of the last meta-block needs when a prefix code is shorter than the byte it lands in; *taking* a read genuinely past the end is `Error::Truncated`.
- Padding bits that the format requires to be zero must be zero: `align()` returns `Error::Padding` when they are not.
- A prefix code that no bit pattern reaches is `Error::Code`; one that is not a prefix code (over- or under-subscribed, or a repeat count that overruns its alphabet) is `Error::CodeLength`; a simple prefix code naming a symbol outside its alphabet, or the same symbol twice, is `Error::Symbol`.
- The maximum backward distance is `0x7FFF_FFFC`. Past it a distance is a static dictionary word instead, and a distance that resolves to zero is `Error::Range`.
- The ring of the last four distances is seeded once per *stream*, not per meta-block: fourth-to-last furthest back, last nearest.
- Block-type symbols 0 and 1 are relative — "the type of the previous block" and "one past the current" — and the rest are literal; a block type past its category is `Error::Range`.
- A meta-block that would produce more bytes than it declared is `Error::Overflow`.
- Static dictionary words are 4 to 24 bytes; a transformed word is the longest base word plus the most bytes any transform adds (13), and the transform buffer is sized accordingly.
- The tables are generated, not transcribed: each blob is checked against the CRC-32 the RFC prints for it — DICT `0x5136cb04`, the transform sequence `0x3d965f81`, Lut0 `0x8e91efb7`, Lut1 `0xd01a32f4`, Lut2 `0x0dd7a0d6` — so a bad transcription fails the generator, which needs the RFC's text to hand, rather than producing a decoder that decodes something else. The committed tables carry the CRC in a comment; nothing re-checks it on every build.

## Side Effects
- Reads only the byte slice handed in; the decoder opens no files, spawns no processes and takes no locks.
- Allocates the output vector and the per-meta-block state (the context map, the prefix-code tables, the distance ring). The 122 784-byte static dictionary is a `static`, not a per-decode allocation.
- Nothing is written to disk and no state survives the call.
